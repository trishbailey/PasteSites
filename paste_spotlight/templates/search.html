Why the previous tool returned nothing

SelectorScope never opened a paste site. The only network call was Google Programmable Search, one site: query per site, and it ran only when both an API key and a search-engine ID were present. This repository has no key. A call without a key returns HTTP 403. When a search did run and Google returned no items, the page said “No results found” with no per-site status. Dead hosts, Cloudflare challenges, and missing indexes looked the same as a clean miss.
